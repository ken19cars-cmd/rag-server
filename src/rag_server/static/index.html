健康檢查

GET /health。嵌入後端、分析模式、Ollama 是否接上、OCR 是否裝好。

案件樹掃描

POST /api/pipeline/detect。讀電腦 A 的 RAG_CASES_ROOT（D:\…\招商案件）。

未完成頁對上資料夾

GET /api/pipeline/local-match。進行中的頁先對頁名，再對地號，再把少寫的縣、市補上。招標完成的頁另外列出。這個對照不改資料夾名稱，也不把分析內容寫進頁面。

GET /api/pipeline/unfilled。只看進行中的頁。招標完成不必套案件介紹範本，不在這一份。捷運聯開這個類別可以沒有 ❯計畫概述，只計件數、不列案名。其他進行中的頁要先有 ❯計畫概述這類標題，伺服器才照標題下面填。還沒套用範本的頁會另列。概述只有範本或頁名，算還沒填。已經寫了本案內容的頁會附上那段概述。不更新 Notion。

POST /api/pipeline/unfilled/analyze。只分析已對上資料夾、而且概述還沒寫本案內容的頁。用該頁真實的 block id 和本地 PDF。招商情形、編輯者、廠商數量、日期進度不進 JSON。不寫入 Notion。

PDF 寫入與合併

POST /api/pipeline/ingest 整樹寫入索引。POST /api/pipeline/extract 合併成分析用文字。有文字層就抽取；掃描頁要 OCR。

問答

POST /api/cases/{id}/query。抽取式，句子必須能在文件裡找到。不走 Ollama。

Notion 分析 JSON

POST /api/notion/analyze。只回第 38 節 JSON（pageId、caseName、baseTable、landUseTable、updates）。不寫入 Notion。有設模型才連電腦 B。

招標完成研究

GET /api/completed 讀 JSON/CSV，或在沒有清單檔時查 Notion「招標完成」。POST /api/completed/research 只抓你貼上的公開網址，並遵守 robots.txt。

Ollama

電腦 B。A 的 RAG_LLM_BASE_URL 指到 http://<B 的 Tailscale IP>:11434/v1，並設定 RAG_LLM_MODEL。兩項都有才啟用。不要對公網開放。

OCR

裝了 Tesseract 才會讀掃描頁。沒裝時掃描頁標成抽不出文字，不會假裝讀到內容。
